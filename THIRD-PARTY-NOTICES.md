- Nunito Sans: Google Fonts distribution, SIL Open Font License; bundled license at `assets/fonts/OFL.txt`.
- Drift's web worker: upstream Drift 2.35.1 release artifact, MIT license at `licenses/drift.txt`.
- SQLite WebAssembly: upstream Drift 2.35.1 release artifact. SQLite is public-domain software; the Dart sqlite3 wrapper's MIT license is at `licenses/sqlite3-dart.txt`.
- Flutter/Dart and packages retain their upstream licenses. Flutter includes package notices in its generated `NOTICES` asset. Dependency versions are pinned in `pubspec.lock`.
- Web audio uses a narrowly patched copy of `audioplayers_web` 5.3.0 (Blue Fire, MIT). Original license and patch provenance are retained in `third_party/audioplayers_web/`; generated Flutter notices include its license. The patch releases audio nodes and suspends idle contexts.
- Earth Core environment and volcanic board frame: original generated project artwork. Expedition tool glyphs: original project vector drawing code. Audio and launcher icons: original procedural project assets; generator sources are under `tool/`.

The project does not incorporate artwork or user-interface assets from benchmark games.
